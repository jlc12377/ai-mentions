How the score is calculated

A live check, not a ranking typed in ahead of time.

We send the same 3–5 buyer questions to each AI assistant that has an API key configured on this site. Examples: “What are the best {category} in {city}?” and “Which {category} companies would you recommend?” The business name is not part of the question. ChatGPT uses the OpenAI web search tool, Perplexity uses Sonar with web search, Gemini uses Google Search grounding, and Claude uses its web search tool. Assistants without a key are skipped.

Mention (70%). 100 points if your business is first in a list, minus 12 points for each step down (floor 20). 50 points if you are named but not in a list. 0 if you are not named. Matching ignores capitalization and suffixes such as Inc, LLC, and Ltd. Your domain counts as a mention when it appears in the answer.

Citation (30%). 100 points if that assistant cites your domain as a source, otherwise 0. This needs the website field. A source on a subdomain counts. A different site that merely contains your domain text does not.

One answer scores 70% of the mention points plus 30% of the citation points. Your visibility score is the rounded average of the answers that actually came back, from 0 to 100. Each answer counts equally. Timeouts and errors are left out of the average and shown under that assistant, so a rate limit on some questions does not look like a miss. If Claude’s web search returns no answer, that question is asked again without search and labeled. If every assistant fails, or none are connected, the page says score temporarily unavailable and does not fill in a number. Identical checks are reused for 24 hours. Very short or generic names can match more often than a distinctive brand.
